# ChocoTumac - Sistema de Gestión

## Descripción
Sistema web para gestión de usuarios, clientes y proveedores con control de roles.

## Tecnologías
- PHP 8
- MySQL
- Bootstrap 5
- MVC

## Funcionalidades
- Autenticación de usuarios
- Control de roles (Admin, Gerente, Empleado)
- CRUD de usuarios
- CRUD de clientes
- CRUD de proveedores

## Seguridad
- Password hashing (bcrypt)
- Validación backend
- Protección de rutas
- Tokens CSRF

## Instalación
1. Clonar repositorio
2. Importar base de datos
3. Configurar `config/database.php`
4. Ejecutar en WampServer
